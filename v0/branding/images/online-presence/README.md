# Build an online presence OG and cover set

One publication image and one image for each of the two posts in the Build an
online presence publication, registered in
`content/publications/online-presence/index.ts`.

Generated by `../../generators/og-covers-v2.py`, except the Build your own blog
card, which came from `og-covers-v4.py` after that post was renamed. Both load
their drawing code from the v1 generator, so this set is visually identical to
the Blog Platform Docs set: same mark, same crop, same title fitting, same green
signal square, same keyword footer.

Every asset is 1200 × 630 and doubles as its Open Graph image and its website
cover. The banner at the top of a page uses this same 40:21 ratio and shows a
card whole; the 16:9 card crop and the square thumbnail crop both take a slice
out of the middle, which is why the title sits in a central safe area.

## Posts

- `posts/501-own-your-platform-og-cover-v1.png` — Own your platform
- `posts/502-build-your-own-blog-og-cover-v1.png` — Build your own blog

The 502 card was redrawn on 2026-08-02 when the post was renamed from "Three ways
to build your own blog". The prefix stays the same because it is the same post.
Note that the v2 manifest still lists the old filename and would write it back if
run again; the file is simply unused, and leaving the manifest alone keeps it an
honest record of what v2 produced.

## Regenerating

Needs Pillow, which is not installed system-wide:

```bash
python3 -m venv .venv
.venv/bin/pip install Pillow
.venv/bin/python v0/branding/generators/og-covers-v2.py
.venv/bin/python v0/branding/generators/og-covers-v4.py
```

Do not overwrite this set for a new exploration. Add a new versioned generator
and new output names, as v2 did alongside v1.
