# Build an online presence OG and cover set

One publication image and one image for each of the two posts in the Build an
online presence publication, registered in
`content/publications/online-presence/index.ts`.

Generated by `../../generators/og-covers-v2.py`, which loads its drawing code
from the v1 generator so this set is visually identical to the Blog Platform
Docs set: same mark, same crop, same title fitting, same green signal square,
same keyword footer.

Every asset is 1200 × 630 and doubles as its Open Graph image and its website
cover. The title sits in a central safe area so the same file survives being
cropped to 16:9 for a card and to the publication's wider banner.

## Publication

- `publication-online-presence-og-cover-v1.png` — Build an online presence

## Posts

- `posts/501-own-your-platform-og-cover-v1.png` — Own your platform
- `posts/502-three-ways-to-build-a-blog-og-cover-v1.png` — Three ways to build your own blog

## Regenerating

Needs Pillow, which is not installed system-wide:

```bash
python3 -m venv .venv
.venv/bin/pip install Pillow
.venv/bin/python v0/branding/generators/og-covers-v2.py
```

Do not overwrite this set for a new exploration. Add a new versioned generator
and new output names, as v2 did alongside v1.
